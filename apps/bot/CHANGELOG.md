# Changelog

All notable changes to the Emberly Discord bot are documented in this file.

The format is based on "Keep a Changelog" and follows [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Fixed

- **Storage and file sizes showed as almost zero** in `/profile`, `/analytics`, `/files` and `/squads`. Emberly reports sizes in megabytes; the bot divided them as if they were bytes.

## [1.0.0] - 2026-10-23

The Emberly bot is now the public **Emberly** app: anyone can add it to their server to use their Emberly account from Discord, run activity levels and offer linked roles. Moderation, server logs and support answers moved to **Warden** (`emberly-mod-bot`), the Emberly server's own bot.

### Upgrading

- Run `bun run prisma:deploy`. Migration `20261023180000_remove_moderation_tables` **permanently drops** `moderation_logs`, `warnings`, `tickets`, `transcripts` and `guild_configs`. Back them up first if you want to keep old warnings or tickets.
- The bot no longer needs any privileged gateway intents. Remove `PRIVILEGED_INTENTS` if you set it.
- See `.env.example` for the full list of variables. `CLIENT_ID` is now only a fallback: the bot registers commands for the application its token belongs to.

### Added

- **Linked roles** — registers three requirements with Discord on startup: has an Emberly account, files uploaded at least N, and member for at least N days. Members connect through embrly.ca.
- **`/levels setup|disable|status`** — set up activity levels (needs Manage Server). Replaces the level options in `/config`.
- **`/rank [user]`** — anyone can check their level and progress. This was previously admin-only.
- **`/files count`** — choose how many recent files to show (1–10).
- `/profile` shows your avatar and plan; `/files` shows the total and marks password-protected files.
- `.env.example` with every variable the bot reads.

### Changed

- **Ember orange** — embeds use the site's `#F97316` instead of the old blue.
- **`/sharex` comes from the site** — the config is generated by embrly.ca, so it uses your preferred upload domain.
- **Clearer errors** — a regenerated upload token now says your link expired and to run `/link` again, instead of "Unauthorized" (and no longer pings the error channel). Requests to Emberly time out after 10 seconds, and outages show a readable message instead of a JSON error.
- The not-linked message points to the new Uploads tab on your profile.
- The bot's status reads "embrly.ca · /help".

### Removed

- Moderation commands (`/ban`, `/kick`, `/timeout`, `/warn`, `/warnings`, `/case`, `/unban`, `/purge`, `/malwarefilter`), `/addroles` and `/config`.
- Server logs, welcome messages, auto-roles, the malicious link filter and prefix commands (`!docs`, `!support`, `!billing` …).

These now live in Warden.

### Fixed

- **Broken links in embeds** — `/shorten` gave `embrly.ca/<code>` instead of `/u/<code>`, `/files` links had a double slash, `/squads` linked to a page that doesn't exist, and `/profile` and `/link` pointed to `embrly.ca/<username>` instead of `/user/<username>`.
- **Login failed with "Used disallowed intents"** — the bot requested privileged intents that weren't enabled for the app.
- **Command registration failed with "not authorized"** — a `CLIENT_ID` from a different application broke registration; the bot now uses its own application ID.
- Long squad and domain lists no longer fail Discord's embed size limits.

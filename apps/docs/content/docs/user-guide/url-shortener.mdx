---
title: Short Links
description: Turn long links into short ones and see how often they're clicked.
---

Emberly turns any long link into a short one like `https://embrly.ca/u/aB3dE7`.

## Create a Short Link

1. Open **Dashboard → Links**.
2. Paste the link you want to shorten.
3. If you have verified [custom domains](/user-guide/custom-domains), choose which domain the short link should use. It starts on your preferred upload domain, or your primary domain if you haven't chosen one.
4. Click **Shorten**. The short link is copied for you.

Links must start with `http://` or `https://`. Links to private or internal addresses, such as `localhost`, aren't allowed.

Short codes are random and 6 characters long. Custom codes aren't supported.

## Clicks

Each short link counts its clicks, shown next to it in **Dashboard → Links**. Totals across all your links are in **Dashboard → Analytics**.

## Delete a Short Link

Delete it from **Dashboard → Links**. It stops working straight away, and anyone who follows it afterwards gets a "not found" page.

## From Code

Create, list and delete short links with the [Short Links API](/api/urls):

```bash
curl https://embrly.ca/api/urls \
  -H "Authorization: Bearer ebk_..." \
  -H "Content-Type: application/json" \
  -d '{"url": "https://example.com/a/very/long/link"}'
```

## Moderation

Short links that break the [rules](https://embrly.ca/legal) can be [reported](/user-guide/reporting). Links removed by moderators show a notice instead of redirecting.

## Uploading Files

### Web Dashboard

1. Go to **Dashboard → Upload**, or drop files anywhere on the dashboard
2. Add files by dropping them or clicking the drop area, then use **Add more** or **Clear** to adjust the list
3. Choose visibility, an optional password, and when to delete the files (**Never**, a preset, or a date)
4. Click **Upload**. Each file shows its progress and speed, and finished uploads stay listed with copy and open buttons until you leave the page

### Supported Upload Methods

| Method | Best For |
|--------|---------|
| Web dashboard | Quick one-off uploads |
| ShareX / Flameshot | Automated screenshot uploads |
| REST API | Programmatic uploads |
| Flicker desktop app | Native desktop workflow |
| PowerShell / Bash | Automation scripts |

## Finding Files

**Dashboard → Files** shows your files newest first. Use the tabs to switch between your files, files shared with you, and your squads' files.

- **Search** matches file names as you type
- **Sort** by date, size, views or downloads
- Filter by **Visibility** (public, private, password protected), **Type**, or a **date range**

Each active filter appears as a chip under the toolbar. Click a chip to remove it, or **Clear all** to start over.

## File Visibility

| Visibility | Who Can Access |
|-----------|---------------|
| **PUBLIC** | Anyone with the URL |
| **PRIVATE** | Only you and named collaborators |

Change visibility anytime from the file's **⋯** menu → **Visibility**.

---

## Password Protection

Add an optional password to any file:

1. Open the file's **⋯** menu → **Add password** (or **Change password**)
2. Enter a password
3. Save

Anyone accessing the file will be prompted for the password. Passwords are bcrypt-hashed server-side — we never see them in plain text.

---

## Expiration Dates

Files can auto-delete on a schedule:

- Set on upload, or afterward from the file's **⋯** menu → **Set expiry**
- Specify a specific date or days from now
- You'll receive an email reminder 2 days before deletion
- Cancel anytime by removing the expiration date

## Sharing

### Get a Share Link

Click any file → **Copy URL**. The URL is immediately shareable.

### Collaborators

Add specific people to access files across all plans:

1. Open file details → **"Add Collaborator"**
2. Enter their email address
3. Choose **View** (download only) or **Edit** (can modify metadata) permission
4. They receive an email invite

Revoke access at any time from the collaborators list.

### Edit Suggestions

Collaborators with the **Suggester** role can submit **edit suggestions** without directly modifying the file; **Editor**-role collaborators can edit directly. You review and accept or reject each suggestion — see [File Collaboration](/user-guide/file-collaboration) for the full role breakdown.

## File Actions

**Copy link** sits next to each file's name. Everything else is in the file's **⋯** menu:

| Action | How |
|--------|-----|
| **Download** | ⋯ → Download |
| **Share** | ⋯ → Share |
| **Visibility** | ⋯ → Visibility |
| **Password** | ⋯ → Add password / Change password |
| **Expiry** | ⋯ → Set expiry / Change expiry |
| **Preview embed** | ⋯ → Preview embed |
| **Extract text** | ⋯ → Extract text (images) |
| **Delete** | ⋯ → Delete (permanent) |

---

## Shared Files

Files shared with you by other users appear in **Dashboard → Files → Shared with me**. You can download and (with edit permission) update metadata.

---

## Chunked Uploads

Files too large for a single request are uploaded in chunks automatically by supported clients. The API also exposes chunked upload endpoints for custom integrations. See the [Files API](/api/files) for details.

---

## OCR (Text Extraction)

On **all plans**, text is automatically extracted from image uploads:

- Search files by their extracted text
- Retrieve OCR results via `GET /api/files/[id]/ocr`
- Processing triggers automatically on upload

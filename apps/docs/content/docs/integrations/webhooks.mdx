---
title: Discord Webhooks
description: Get your Emberly notifications in a Discord channel.
---

Emberly can post your notifications to a Discord channel through a webhook, as well as or instead of emailing you.

## Set It Up

1. In Discord, open the channel's settings, go to **Integrations → Webhooks**, create a webhook and copy its URL.
2. In Emberly, open **Profile → Notifications**.
3. Paste the URL into **Discord webhook** and click **Save**. Discord notifications turn on, and **Send test** posts a test message.

Only Discord webhook URLs (`https://discord.com/api/webhooks/...`) are accepted.

## What Gets Sent

Each notification is posted as an embed with its title, a link to the right page, and a color for its category. Choose which categories go to Discord in the **Discord** column of the notification settings. They're the same categories as email and the site, set separately:

| Category | Examples | On by default |
|----------|----------|---------------|
| **Security** | New sign-ins, password and 2FA changes, API keys | Yes |
| **Account** | Email changes, applications, shared files, data exports | No |
| **Billing** | Payments, subscriptions and refunds, where billing is on | Yes |
| **Product updates** | Perks, extra storage, new features | No |
| **Announcements** | Offers and newsletters | No |

## Webhooks for Other Apps

Emberly doesn't send webhooks to your own apps yet. To react to new uploads, poll [`GET /api/files`](/api/files#list-your-files) with `sortBy=newest`.

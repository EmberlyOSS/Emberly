Flicker is a [Tauri](https://tauri.app) app: a React and TypeScript interface on top of a Rust core. The code is at [EmberlyOSS/Flicker](https://github.com/EmberlyOSS/Flicker).

## Prerequisites

| Tool | Version |
|------|---------|
| [Bun](https://bun.sh) | 1.3+ |
| [Rust](https://rustup.rs) | Latest stable |
| Tauri system dependencies | See [Tauri's prerequisites](https://v2.tauri.app/start/prerequisites/) for your system |

On Linux that means the WebKitGTK and build packages; on Windows, the Visual Studio C++ build tools and WebView2; on macOS, the Xcode command line tools.

## Run It

```bash
git clone https://github.com/EmberlyOSS/Flicker.git
cd Flicker
bun install
bun run tauri:dev
```

This opens Flicker with hot reload for the interface. Changes to the Rust code rebuild the app automatically.

## Build Installers

```bash
bun run tauri:build
```

Installers for your current system are written to `src-tauri/target/release/bundle/`.

Official releases are built by GitHub Actions for Windows, macOS (Apple silicon and Intel) and Linux whenever a release is published. The updater artifacts are signed there, so local builds can't update themselves.

## Project Layout

| Path | What it is |
|------|-----------|
| `src/` | The React interface: pages, settings, hooks |
| `src/components/overlays/` | The region capture overlay |
| `src-tauri/src/` | The Rust core: capture, hotkeys, uploads, tray and updates |
| `src-tauri/tauri.conf.json` | App, window and bundle configuration |

## Talking to Emberly

Flicker uses the public [Emberly API](/api): [device sign-in](/api/device) to get its own API key, [`POST /api/files`](/api/files#upload-a-file) to upload, and [`GET /api/instance`](/api#server-information) to see what the server supports.

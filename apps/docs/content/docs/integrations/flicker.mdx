**Flicker** is Emberly's own desktop app. Press a shortcut, pick an area, and the link is on your clipboard a moment later. It connects to embrly.ca.

## Download

Get the installer for your system from the [Flicker releases page](https://github.com/EmberlyOSS/Flicker/releases):

| System | Download |
|--------|----------|
| **Windows** | `.msi` or `.exe` installer |
| **macOS** | `.dmg`, for Apple silicon or Intel |
| **Linux** | `.AppImage`, `.deb` or `.rpm` |

Flicker updates itself: **Settings → About** checks for new versions and installs them.

<Callout type="info">
  The installers aren't code-signed yet, so Windows may show "unknown publisher" and macOS "unidentified developer". On macOS, right-click Flicker and choose **Open** the first time.
</Callout>

## Sign In

Open Flicker and choose how to sign in:

- **Sign in with your browser** (recommended). Flicker shows a short code and opens embrly.ca. Check the code matches and click **Approve**. Flicker gets its own key, named after your computer, which you can revoke any time in **Profile → API** on the website.
- **Email and password**, if you'd rather not use the browser.
- **Upload token**, pasted from **Profile → Uploads** on the website.

## Capture and Upload

| Action | Default shortcut | What it does |
|--------|------------------|--------------|
| **Capture region** | `Ctrl+Shift+X` | Drag an area on any screen, or click once to capture a window |
| **Capture screen** | `Ctrl+Shift+S` | The screen your cursor is on |
| **Capture all screens** | `Ctrl+Shift+A` | Every monitor in one image |
| **Record video** | `Ctrl+Alt+R` (`Cmd+Shift+R` on macOS) | Press again to stop |
| **Upload clipboard** | `Ctrl+Alt+U` | Upload a copied image or file |

Shortcuts work while Flicker is in the background. Change them in **Settings → Hotkeys**; **Reset to defaults** puts them back.

You can also drag files onto Flicker's **Upload** page, or use the quick actions there.

When an upload finishes, the link is copied to your clipboard and you get a notification with a sound. You can change both in **Settings → Preferences**.

## Pages

| Page | What's there |
|------|--------------|
| **Upload** | Quick actions for every capture type, drag and drop, and your recent uploads |
| **History** | Your latest 100 files from Emberly, including ones uploaded from the website or other devices |
| **Shorten** | Shorten a link; the short link is copied as soon as it's ready |
| **Stats** | Uploads over the last 14 days, with views and downloads |
| **Settings** | Account, Capture, Hotkeys, Preferences and About |

## Settings

| Tab | Settings |
|-----|----------|
| **Account** | Who you're signed in as, your upload token, perks, and signing out |
| **Capture** | Screenshot and recording options, default visibility and password for uploads, and which domain links use |
| **Hotkeys** | Every shortcut |
| **Preferences** | Theme, text size, sounds, notifications, what's copied after an upload, and running in the background |
| **About** | Updates, the activity log, console logs for bug reports, and links |

## macOS Permissions

Flicker needs **Screen Recording** to capture the screen, and **Accessibility** for shortcuts to work in other apps. **Settings → Capture** shows whether each is granted, with a button to open the right System Settings page. After granting Screen Recording, quit and reopen Flicker.

The same section shows whether Flicker starts at login. On macOS, closing the window keeps Flicker running in the menu bar.

## Troubleshooting

| Problem | Try |
|---------|-----|
| A shortcut does nothing | Another app may use the same keys. Pick a different one in **Settings → Hotkeys**. On macOS, check Accessibility permission. |
| Screenshots are black or only show the wallpaper (macOS) | Grant Screen Recording, then quit and reopen Flicker. |
| Uploads fail | Check you're still signed in under **Settings → Account**. If you revoked Flicker's key on the website, sign in again. |
| Something else | **Settings → About → Activity log** shows what went wrong. Copy the console logs into a [bug report](https://github.com/EmberlyOSS/Flicker/issues/new?template=bug_report.md). |

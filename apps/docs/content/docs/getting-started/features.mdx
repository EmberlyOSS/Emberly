## Uploads

- **Any file type**, apart from executables and other types blocked for safety
- **Drag and drop** onto the dashboard, or drop files anywhere on the page
- **Large files** upload in parts, with a progress bar
- **Screenshot tools**: [Flicker](/integrations/flicker), [ShareX](/integrations/sharex), [Flameshot](/integrations/flameshot) and Spectacle
- **Upload from code** with the [REST API](/api), using an API key

## Sharing

| Option | What it does |
|--------|--------------|
| **Public link** | Anyone with the link can open the file |
| **Private** | Only you can open it |
| **Password** | Viewers enter a password first |
| **Expiry** | Delete the file, or make it private, at a set time |
| **Link previews** | Images and videos show inline in Discord and other apps |
| **Raw link** | Add `/raw` to a link to get just the file, for embedding |

## Text and Code

- **[Pastes](/user-guide/paste)** with syntax highlighting
- **[Collaborators](/user-guide/file-collaboration)** who can edit text files, or suggest changes for you to accept
- **Text in images**: Emberly reads text in uploaded images, so you can find screenshots by what's in them

## Short Links

Turn any long link into a short one with [the link shortener](/user-guide/url-shortener), and see how many times each is clicked.

## Your Own Domain

Serve your uploads from a domain you own, like `files.example.com`. Set it up with a single DNS record, or let Emberly do it for you on Cloudflare. HTTPS is handled for you. See [Custom Domains](/user-guide/custom-domains).

## Analytics

Views, downloads and storage over time, your most popular files, and a CSV export.

## Security

- **[Malware checks](/security/virustotal)** on uploads, using VirusTotal
- **Zip bomb detection** and blocked dangerous file types
- **[Breached password warnings](/security/hibp)** using Have I Been Pwned
- **Two-factor authentication** with an authenticator app, plus recovery codes
- **Signed-in device list** and sign out everywhere
- **[Report](/user-guide/reporting)** files, links and users that break the rules

## Teams and Profiles

- **[Squads](/user-guide/teams-and-squads)**: shared storage and uploads for a team
- **[Discovery](/user-guide/nexium)**: a public profile and squad listings
- **[Discord bot](/user-guide/discord-bot)** and linked roles for your server

## Run It Yourself

Emberly is free to [self-host](/self-hosting) with Docker in a few minutes.

## Account

### Is Emberly free?

Yes. embrly.ca is free, with the same [limits](/getting-started/limits) for everyone. If you need more storage or domains, you can ask for them. [Self-hosting](/self-hosting) is free too.

### How do I reset my password?

Click **Forgot password?** on the login page, enter your email, and follow the link we send you.

### Can I sign in with GitHub or Discord?

No, you always sign in with your email. You can link GitHub and Discord in **Profile → Connections** for [perks](/user-guide/contributor-perks) and Discord roles.

### How do I delete my account?

Go to **Profile → Data**, choose **Delete account** at the bottom and enter your password to confirm. Your files, links and data are deleted straight away and can't be recovered, so export a copy first from the same page if you want one.

## Files

### What can't I upload?

Executables and scripts, such as `.exe`, `.bat` and `.ps1`, along with zip bombs and files VirusTotal reports as malware. Almost everything else is fine.

### How big can my files be?

It depends on your upload limit, shown in **Profile → Uploads**. See [Limits](/getting-started/limits).

### Can I password-protect a file?

Yes, when uploading or afterwards from the file's menu. Viewers have to enter the password before they can open the file. Passwords are stored hashed.

### Can a file delete itself?

Yes. Set an expiry date when uploading or afterwards. At that time the file is deleted, or made private if you prefer. You can set a default for new uploads in **Profile → Settings**.

### How do I share a private file with one person?

Add a password and send it to them along with the link. To let someone work on a text file with you, add them as a [collaborator](/user-guide/file-collaboration).

### Why doesn't my link show a preview in Discord?

Previews don't show for private or password-protected files. If you changed a file recently, Discord may be showing an old preview; post the link again in a new message. To get a plain image instead of a card, turn off **rich embeds** in **Profile → Settings**.

## Security and Privacy

### Do you scan my uploads?

Yes. Emberly sends the file's fingerprint (a SHA-256 hash), not the file itself, to [VirusTotal](/security/virustotal) and removes files known to be malware.

### What's the breached password warning?

When you sign in, Emberly checks your password against [Have I Been Pwned](/security/hibp) without ever sending it. Only the first 5 characters of a hash of it leave the server. If it's appeared in a breach, you're asked to change it.

### Should I turn on two-factor authentication?

Yes. Set it up in **Profile → Security** with any authenticator app, and keep the recovery codes somewhere safe.

## Custom Domains

### How many domains can I add?

See [Limits](/getting-started/limits). Contributors and Discord boosters [get extra](/user-guide/contributor-perks).

### How do I set one up?

Point a `CNAME` record at `cname.emberly.site` and click **Verify**, or let Emberly create the records on Cloudflare for you. HTTPS is set up automatically. See [Custom Domains](/user-guide/custom-domains).

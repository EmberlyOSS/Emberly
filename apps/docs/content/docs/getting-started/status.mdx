title: Service Status
description: Check whether embrly.ca is working, and get told when it isn't.
---

The live status page for embrly.ca is **[emberlystat.us](https://emberlystat.us)**. It shows the health of uploads, the website, the API and storage, plus any ongoing incidents and planned maintenance.

## Get Notified

Sign in on [emberlystat.us](https://emberlystat.us) and subscribe to get an email when an incident starts or is resolved, and before planned maintenance.

## Check From Code

`GET https://embrly.ca/api/status-indicator` returns the current status without needing an account. It's what the status badge in the site footer uses.

```json
{
  "configured": true,
  "url": "https://emberlystat.us",
  "indicator": "NONE",
  "description": "All systems operational",
  "maintenance": false,
  "incident": null
}
```

| `indicator` | Meaning |
|-------------|---------|
| `NONE` | Everything is working |
| `MINOR` | Something is slow or partly down |
| `MAJOR` | A main feature is down |
| `CRITICAL` | Emberly is down |
| `UNKNOWN` | The status page couldn't be reached |

`incident` holds the `name` and `url` of the latest unresolved incident. On a self-hosted instance without a status page, the response is `{ "configured": false }`; see `STATUS_PAGE_URL` to connect one.

For a deeper check of a server, including the database and storage, use [`GET /api/health`](/self-hosting/production#health-checks).

## Report a Problem

If something's broken and the status page doesn't show it yet:

- Ask in the [Emberly Discord](https://discord.gg/36spBmzZVB)
- Email [support@embrly.ca](mailto:support@embrly.ca)

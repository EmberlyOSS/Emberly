Emberly is for sharing files, screenshots, short links and pastes. You can use it for free at [embrly.ca](https://embrly.ca), or [run your own](/self-hosting).

## 1. Create an Account

Sign up at [embrly.ca/auth/register](https://embrly.ca/auth/register) with your email and a password, then click the link in the verification email. You can't upload until your email is verified.

<Callout title="No email?">
  Check your spam folder, or request a new link from the login page.
</Callout>

You can link GitHub and Discord later in **Profile → Connections** for [perks](/user-guide/contributor-perks), but you always sign in with your email.

## 2. Find Your Way Around

Everything is in the [dashboard](https://embrly.ca/dashboard):

| Page | What's there |
|------|--------------|
| **Overview** | Storage used and recent activity |
| **Files** | Everything you've uploaded: search, filter, edit and delete |
| **Upload** | Upload files from your computer |
| **Paste** | Share text and code with syntax highlighting |
| **Links** | Your short links |
| **Analytics** | Views, downloads and storage over time |

Account settings, upload tools and API keys live under your avatar in **Profile**.

## 3. Upload a File

Drag files onto **Upload**, or click to choose them. Each file gets a link straight away, like `https://embrly.ca/aB3dE/photo.png`.

To upload screenshots automatically, set up a screenshot tool:

| Tool | Platforms | Guide |
|------|-----------|-------|
| **Flicker** | Windows, macOS, Linux | [Flicker](/integrations/flicker), Emberly's own app |
| **ShareX** | Windows | [ShareX](/integrations/sharex) |
| **Flameshot** | Linux, macOS | [Flameshot](/integrations/flameshot) |

## 4. Share It

Copy a file's link from **Files** and send it anywhere. In Discord and other chat apps it shows a preview of the image or video.

From a file's menu you can also:

- **Make it private**, so only you can open it
- **Add a password** that viewers have to enter
- **Set an expiry date**, after which it's deleted or made private
- **Add collaborators**, who can edit or suggest changes to text files

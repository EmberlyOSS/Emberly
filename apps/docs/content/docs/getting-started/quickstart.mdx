This takes you from a new account to uploading from code. If you'd rather use the website, see [Getting Started](/getting-started).

## 1. Create an API Key

1. Sign in to [embrly.ca](https://embrly.ca).
2. Open **Profile → API** and create a key. Give it a name you'll recognise, like "Backup script".
3. Copy the key. It starts with `ebk_` and is only shown once.

<Callout type="warn" title="Keep it secret">
  An API key can do anything your account can. Don't commit it to a repository or put it in code that runs in a browser. You can revoke it in **Profile → API** at any time.
</Callout>

## 2. Upload a File

### cURL

```bash
curl https://embrly.ca/api/files \
  -H "Authorization: Bearer ebk_..." \
  -F "file=@photo.png"
```

### JavaScript

```typescript
const form = new FormData()
form.append('file', file)

const res = await fetch('https://embrly.ca/api/files', {
  method: 'POST',
  headers: { Authorization: `Bearer ${process.env.EMBERLY_API_KEY}` },
  body: form,
})

const { data } = await res.json()
console.log(data.url)
```

### Python

```python
import os
import requests

with open("photo.png", "rb") as f:
    res = requests.post(
        "https://embrly.ca/api/files",
        headers={"Authorization": f"Bearer {os.environ['EMBERLY_API_KEY']}"},
        files={"file": f},
    )

print(res.json()["data"]["url"])
```

### PowerShell

```powershell
$headers = @{ Authorization = "Bearer $env:EMBERLY_API_KEY" }
$res = Invoke-RestMethod -Uri "https://embrly.ca/api/files" `
  -Method Post -Headers $headers -Form @{ file = Get-Item ".\photo.png" }
$res.data.url
```

## 3. Use the Response

```json
{
  "success": true,
  "data": {
    "id": "clx9k2m...",
    "url": "https://embrly.ca/aB3dE/photo.png",
    "name": "photo.png",
    "size": 204800,
    "type": "image/png"
  }
}
```

`url` is the link to share. Keep `id` if you want to change or delete the file later.

## 4. Upload Options

Add these as form fields:

| Field | Values | Description |
|-------|--------|-------------|
| `visibility` | `PUBLIC` (default) or `PRIVATE` | Private files are only visible to you. |
| `password` | any text | Viewers must enter it to open the file. |
| `expiresAt` | ISO 8601 date | Delete the file at this time. |
| `domain` | one of your verified domains | Use it in the returned link. |

```bash
curl https://embrly.ca/api/files \
  -H "Authorization: Bearer ebk_..." \
  -F "file=@report.pdf" \
  -F "visibility=PRIVATE" \
  -F "password=s3cret" \
  -F "expiresAt=2026-12-31T23:59:59Z"
```

## 5. Large Files

For files close to your upload limit, or anything over a few hundred megabytes, upload in parts so a dropped connection doesn't mean starting again. See [Large Files](/api/files#large-files).

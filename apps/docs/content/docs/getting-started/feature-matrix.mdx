## Legend

- ✓ — Feature included
- ∞ — Unlimited
- — — Not included

The REST API has no general per-plan rate limit; a small number of security-sensitive endpoints (registration, password reset, etc.) have flat limits regardless of plan — see the [API rate limits](/docs/api/user-reference#rate-limits) reference. Outbound webhooks are not available on any plan yet — see [Webhooks](/docs/integrations/webhooks).

## Unsure Which Plan You Need?

- **Just starting?** Try **Spark** (free)
- **Regular file sharing?** **Glow** is perfect
- **Large file uploads?** **Flare** has 2 GB files
- **Running a team?** **Blaze** has team features
- **Enterprise scale?** **Inferno** or **Ember**

See the [Plans Overview](/docs/getting-started/plans-overview) for more details about each tier.

## Quick Start

With Docker installed, you only need two files. PostgreSQL and Redis come with them:

```bash
mkdir emberly && cd emberly
curl -fsSLo compose.yaml https://raw.githubusercontent.com/EmberlyOSS/Emberly/main/compose.yaml
curl -fsSLo .env https://raw.githubusercontent.com/EmberlyOSS/Emberly/main/.env.example
# set AUTH_SECRET (openssl rand -base64 32) and APP_URL in .env
docker compose up -d
```

Open `http://localhost:3000` and the [Setup Wizard](/docs/self-hosting/first-time-setup) walks you through creating the admin account. Database migrations run automatically when the container starts.

For other ways to deploy, see [Deploying](/docs/self-hosting/production).

## What You Need

| Component | Version | Notes |
|-----------|---------|-------|
| PostgreSQL | 14+ | Bundled in the Compose file |
| Redis | 7+ | Bundled in the Compose file |
| Storage | — | A local volume by default, or any S3-compatible bucket |
| Server | 2 GB RAM | More if you enable OCR on large uploads |

## Configuration Model

Only a few things must be set before the first start: `APP_URL`, `AUTH_SECRET`, `DATABASE_URL` and `REDIS_URL`. Everything else, including email, storage and integrations, can be set either as environment variables or later in **Admin → Settings**. When both are set, environment variables win for storage, and the Admin Panel value wins for email.

See [Environment Variables](/docs/self-hosting/environment) for the full list.

## Repository Layout

Emberly is a monorepo. The app you deploy lives in `apps/dashboard`; the other apps are optional.

| Path | What it is |
|------|-----------|
| `apps/dashboard` | The Emberly web app, API and background worker |
| `apps/docs` | This documentation site |
| `apps/bot` | The Emberly Discord bot |
| `packages/db` | Prisma schema and migrations |
| `packages/config` | Shared TypeScript and lint config |
